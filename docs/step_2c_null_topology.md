## Joint empirical-null convention

For each relation (`same_city`, `cross_city`) and each measured metric (`local_match_ratio`, `num_matches`), reconstruct the exact smallest raw value satisfying:

```text
F_null(x) = count(null_value <= x) / N >= q
q in {0.95, 0.99}
```

Use distinct observed values and cumulative tie counts, without interpolating quantiles. Save ratio/count q95/q99 raw thresholds and realized marginal tail counts/fractions. The tail includes the threshold value. For illustration, a null containing the 100 distinct integers 0–99 has weak-ECDF q95 threshold 94, giving six qualifying observations; q99 threshold 98 gives two. Ties can increase realized tail mass further. These examples are mathematical fixtures, not pilot measurements.

For every random control, use its own frozen relation population, including itself, for both percentiles:

```text
random_structural_bottleneck = min(random_ratio_percentile, random_count_percentile)
random_core_q95 = random_structural_bottleneck >= 0.95
random_core_q99 = random_structural_bottleneck >= 0.99
```

This matches the Step 2B empirical-null convention. Do not independently multiply marginal tail rates. Save joint counts/fractions for all controls and each relation, and compare with candidate rates from the validated frozen core flags. Candidate rates retain the Step 2B exact-duplicate exclusion; the requested random joint criterion has no additional duplicate gate.

Report `candidate_fraction / random_fraction` and `candidate_fraction - random_fraction`; a zero or undefined denominator yields a null rate ratio. These are descriptive enrichment quantities, without a recognition-performance interpretation.

The leave-one-out sensitivity removes the same random control from both metric nulls:

```text
F_LOO(own_value) = (count(null_value <= own_value) - 1) / (N - 1)
```

Other observations tied with it remain. An N=1 relation has undefined LOO percentiles/flags and is excluded from the sensitivity denominator, explicitly recorded. The real frozen relations have many more controls. Primary results remain self-inclusive.

## Paired evidence

Align random controls by `candidate_pair_uid` against candidate `pair_uid`, enforcing one-to-one alignment and identical relation/rank metadata. The unpaired candidate remains in full candidate-rate calculations. The paired table contains 4,999 comparisons.

Both sides use identically reconstructed weak-ECDF arithmetic; candidate bottlenecks are checked against frozen Step 2B values with absolute tolerance `1e-12`. This prevents CSV roundtrip noise from changing a true tie into a win or loss. Original Step 2B files and candidate core labels are untouched.

Candidate raw matching ratios come directly from the frozen Step 2A measurements, aligned to graph rows by unique pair UID and checked against graph identity, relation, rank, match count, duplicate flag and ratio. Re-serializing a ratio into the Step 2B graph CSV can slightly change its parsed float, breaking an exact tie with a random control and shifting the reconstructed ECDF. Using the original measurement values preserves the calibration convention without rounding, epsilon-based tie grouping, relaxed percentile validation, or modifications to graph inputs. Topology analysis continues to use the frozen graph table unchanged. Stages 14 and 16 share this binding.

Save candidate >, == and < random counts, candidate-win fraction, and delta-bottleneck mean, sample standard deviation, minimum, q05, q25, median, q75, q95 and maximum. Report all, same-city, cross-city and the five frozen SALAD rank bins. Empty groups use null summaries; sample standard deviation is undefined with fewer than two observations.

## Fixed-graph topology null

Keep all candidate image/place endpoints, pair identities, SALAD evidence, city relations, distances, and candidate degree distributions fixed. Move these fields together:

```text
ratio_null_percentile
match_count_null_percentile
structural_bottleneck
structural_geomean
core_q95
core_q99
```

Never independently shuffle ratio and count. Permutations exchange bundles only within the Cartesian product of:

- Same/cross-city relation.
- `rank_1`, `rank_2_5`, `rank_6_10`, `rank_11_20`, `rank_21_50`.
- `[250,500)` m and `>=500` m geographic status.

Save all 20 stratum counts, including empty strata and their q95/q99 edge counts; strata below two edges remain unchanged. Report empty/singleton counts and the number of unchanged edges. Core labels move as part of the bundle; do not add a new duplicate gate after reassignment. The geo500 label is recalculated from the moved core label and fixed distance.

Each permutation uses NumPy `PCG64(SeedSequence([seed, zero_based_permutation_index]))`, with input rows sorted by pair UID. Any index can be reproduced without generating preceding indices. Independently seeded realizations can coincide by chance, especially in small strata; they are not forced to be distinct. Software versions are recorded. The implementation retains one small 5,000-edge bundle matrix and scalar permutation statistics, without local features or full-dataset processing.

For q95, q99 and q95_geo500, each permutation reports:

- Selected image-edge count, repeated place pairs with >=2 and >=3 supports, and strict core-only independent support with >=2 and >=3 supports.
- Active places, non-singleton place components, largest place component and maximum place degree.
- Active images, largest image component and maximum image degree.

Independent support always requires two distinct selected images on **both canonical place sides**. Weak supporting edges do not contribute distinct core views. Place degree uses the simple place graph, collapsing repeated image supports into one place-pair edge. The full endpoint universe is fixed; an empty slice on a nonempty universe has largest singleton size 1.

Observed values are rebuilt from Step 2B CSVs and checked against the frozen snapshot, including its q95/q99 counts, component sizes/degrees and strict repeated support. The historical numbers are never used as unchecked literal outputs.

`topology_permutations.csv` stores the full distribution for all statistics. Columns use `slice__statistic`, including `core_q95__repeated_support_2`, `core_q95__core_independent_support_2`, `core_q95__largest_place_component`, and `core_q95__max_place_degree`. The snapshot reports observed value, null mean/sample std/min/q05/q25/median/q75/q95/q99/max, and:

```text
empirical_exceedance_fraction =
    (1 + count(permutation_value >= observed)) / (1 + num_permutations)
```

This is a diagnostic exceedance fraction, not a definitive hypothesis-test p-value. No threshold is learned from the permutation output.
